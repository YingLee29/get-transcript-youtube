Cài đặt

Chạy server AI (một lần)

  1. Cài Python 3.10–3.12 và ffmpeg.
  2. Mở Terminal tại thư mục dự án.
cd server
pip install -r requirements.txt
python app.py

Lần chạy đầu, model sẽ được tải về (small ≈ 480 MB). Sau đó server chạy tại http://127.0.0.1:8765.

Mẹo

  • Lấy phụ đề: nhanh, miễn phí, cần video có phụ đề (kể cả tự động).
  • AI nghe & viết: chậm hơn nhưng chính xác với video tiếng Việt không có phụ đề.
  • Video dài 30 phút có thể mất 3–10 phút tuỳ máy.
  • Video giới hạn tuổi / riêng tư: dùng --cookies-from-browser chrome khi chạy server.
